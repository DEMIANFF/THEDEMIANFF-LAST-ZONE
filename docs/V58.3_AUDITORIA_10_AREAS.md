# THEDEMIANFF LAST ZONE — V58.3.0 quality pass

## Verified product scope

The current client is an Android/WebView single-player Battle Royale prototype with local AI opponents. It is not a live 100-player online match client. Google sign-in, sequential player identity assignment and per-account Firestore progress backup exist; those do not synchronize live combat state.

## Multiplayer implementation gate

Before claiming online Battle Royale, implement and deploy authenticated matchmaking/room allocation; authoritative server ticks for movement, damage, inventory, zone and eliminations; low-latency bidirectional transport; reconnect/session recovery; server-side anti-cheat validation; room cleanup/rate limits; and Firestore security/rules tests. Never trust client-reported kills, credits, XP or match results.

## Device acceptance checklist

1. Install the signed release over V58.2.1 without uninstalling.
2. Start a match, parachute and land near/inside a building.
3. Collect ammo with each weapon selected and confirm only that weapon's reserve changes.
4. Test healing while outside the safe zone; healing must cancel and health must decrease.
5. Run, stop, crouch, aim and fire with Lila; inspect animation blend and camera comfort.
6. Observe FPS/resolution telemetry after several minutes on Motorola Edge 60 Fusion.
7. Sign in with Google, save, and verify recovery separately on a second install/device.

No device-only acceptance item is considered passed by CI.
