- Procedural AWM model with scope tube, rings, lens, bolt handle and bipod.
- Camera input in aircraft and freefall/parachute descent, independent of the ground joystick region.
- Deployment map with named Base Aurora POIs, aircraft route, selectable destination, zoom controls and return to flight.
- Parachute deployment eases in over 0.62 seconds, changes descent speed and animates body/canopy steering.
- Preserves V58.8 lobby clarity: single Arsenal entry, compact dock, cleaned brand label, player identity and backup modules.
