# Aurora V2: P90 original

**Modular P90 Tactical** — doomsentinel.
Source: https://sketchfab.com/3d-models/modular-p90-tactical-080897fc0366455884b1a916684313fe
License: Creative Commons Attribution 4.0, https://creativecommons.org/licenses/by/4.0/

The original delivered by the user is pinned by SHA-256 in
`tools/build_p90_mobile.py`. Its embedded author, source and license match the
creator's published model listing, checked on 2026-11-25.

Changes: embedded textures resized to at most 512 pixels; redundant blending
removed only when alpha is entirely opaque. Geometry, UVs and materials retain
the original model. The GLB has no original animation clips. Operator movement,
reload and equip actions use Lila's existing derived animation system.

HK416 and VSS retain their historical optional paths. This folder does not
pretend those two models have been installed or approved for distribution.
