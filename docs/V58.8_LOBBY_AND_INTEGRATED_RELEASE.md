# THEDEMIANFF LAST ZONE — V58.8.0 integrated release

This is a single consolidated V58.8.0 release, not five separate APKs. It integrates the V58.4–V58.7 quality milestones and the V58.8 lobby evolution. It retains the tested V58.3 gameplay corrections.

## Lobby organization

- Top: current player identity, level, XP, credits and settings.
- Left rail: shop, Aurora pass, operators and operations.
- Center: existing live Three.js operator stage with touch drag rotation.
- Right rail: selected weapon's real damage, magazine and range; current mode and local-AI opponent count.
- Bottom dock: inventory, weapons, loadouts and the existing unique START control.
- Social entry remains accessible but states accurately that online rooms and friend presence are not enabled.

The weapon summary reads the selected weapon directly from the player profile. Lobby buttons route through existing store, operator, pass, operations, inventory, arsenal, preset and social panels. The match is launched only by the existing START button.

## Explicitly excluded

V59.0.0 live multiplayer is not part of this release. The current game remains a local-AI Battle Royale prototype. The social screen must not claim live friends, parties, rooms or matchmaking. A future online release requires an authenticated authoritative match server, realtime transport, matchmaking, reconnect support, server-side combat/economy validation, abuse controls and deployed security rules.

## Motorola acceptance checklist

1. Install the signed release over the previous signed version without uninstalling.
2. Confirm player name, five-digit account ID, level, XP and credits remain visible.
3. Drag the 3D operator horizontally and confirm smooth 360-degree rotation.
4. Open Store, Pass, Operators, Operations, Inventory, Arsenal, Loadouts and Social.
5. Select another weapon and confirm the right-side name, damage, magazine and range update.
6. Switch between Survival and Training and confirm opponent count changes from 20 to 8.
7. Start each mode with the unique START button.
8. Test landscape phone layout and the Motorola Edge 60 Fusion after several minutes for FPS, temperature and touch responsiveness.

CI can verify source contracts and compilation, but it cannot replace these physical acceptance checks.
